# 📖 Sobre

**Beigar RPG** é um jogo de RPG desenvolvido em **Python**, onde o jogador embarca em uma aventura pelo reino de **Beigar** em busca do lendário **Cetro Milenar**.

Ao longo da jornada, o jogador enfrenta criaturas poderosas, coleta equipamentos, administra um inventário, utiliza itens especiais e toma decisões que influenciam diretamente o desenrolar da história.

Além da lógica do jogo, o projeto também conta com uma **interface gráfica desenvolvida em Tkinter**, proporcionando uma experiência mais agradável ao usuário.

# ▶️ Como Executar

